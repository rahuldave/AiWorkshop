# Document practice

Use an approved chat assistant for this exercise. You can also compare prompts on paper.

The document below is fictional. It contains all the information needed for the exercise.

## Practice document

```text
Page 1. Booking terms

The course starts on 12 May.
The standard fee is $600 per participant.
The fee for partner organizations is $450 per participant.

Page 2. Payment terms

Invoices are due within 20 calendar days of receipt.
Cancellation requires 10 calendar days' notice.
```

## Your task

Find the standard fee, partner fee, payment deadline, and minimum group size.

1. Copy the practice document into your approved chat assistant.
2. Write a prompt for the task.
3. Check each answer against the document.
4. Change one instruction and run the prompt again.

Keep both prompts and both answers. Record the change and whether it helped.

## A prompt to try

```text
Extract the standard fee, partner fee, payment deadline, and minimum group size.
Use only the supplied document.
Return a table with the field, answer, quote, and page.
If the document gives no answer, write "Not stated".
Keep the two fees separate.
```

## Checks

- **Task.** Every requested field appears.
- **Evidence.** Each quote supports its answer.
- **Exceptions.** The two fees stay separate.
- **Missing facts.** Unstated details stay "Not stated".

## A prompt for an AI check

Give the checker the practice document and the answer. Then use the request below.

```text
Compare the answer with the document.
For each field, report supported, unsupported, or missing.
Quote the passage behind each judgment.
```

Check the feedback against the document yourself. The checker can also make mistakes.
