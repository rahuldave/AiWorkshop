# AI training workshop

A workshop for people who want to understand AI and use it in their work.

The workshop runs from 10:00 AM to 3:00 PM. It uses everyday examples, discussion, and practical activities.

## Presentations

| Session | Topic | Status |
| :--- | :--- | :--- |
| 1 | Embeddings and language models | [PowerPoint draft](output/01-AI-Context.pptx) |
| 2 | AI agency and the ecosystem we want | Planned |
| 3 | AI tools and prompt engineering | Planned |
| 4 | AI agents | Planned |
| 5 | From learning to action | Planned |

The first deck has 22 slides, including a source slide. Speaker notes include explanations, timing, and source links.

It combines adapted slides from Rahul Dave's teaching presentations with new slides that explain each step in plain language.
